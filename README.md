# Simulateur Budgétaire PCPE Autisme Chrysalide

👉 **[Accéder à l'application en ligne](https://Miki64.github.io/associationchrysalide_pcpe/)** 👈

## Fonctionnalités
Outil de pilotage financier et de simulation budgétaire pensé pour la structure "PCPE Autisme" de l'Association Chrysalide.

- Suivi du budget global et prévisionnel
- Saisie des prestations mensuelles
- Calendrier annuel détaillé avec écarts
- Exports Excel et PDF
- Mode local (les données sont sauvegardées dans votre navigateur)

## Lancement en local
```bash
npm install
npm run dev
```
